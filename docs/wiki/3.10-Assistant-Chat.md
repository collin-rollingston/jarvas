# Assistant Chat

Open Assistant from the app's navigation. It provides a thread rail, a
new-thread action, prompt suggestions, and a chat composer. Use **Back to
tasks** in the chat header to return to the existing task interface.

For local development, configure CLOUDFLARE_ACCOUNT_ID and
CLOUDFLARE_API_TOKEN in the ignored .env.local file at the repository root
beside package.json, then restart the app:

```dotenv
CLOUDFLARE_ACCOUNT_ID=your-account-id
CLOUDFLARE_API_TOKEN=your-workers-ai-api-token
```

Use npm start for the desktop app or npm run startFrontend for the browser
development app. A custom Cloudflare API token needs Workers AI Read and Edit
permissions.

The local development connection uses Cloudflare Workers AI with
@cf/google/gemma-4-26b-a4b-it. Cloudflare documents the [Workers AI REST API
setup](https://developers.cloudflare.com/workers-ai/get-started/rest-api/) and
[function calling](https://developers.cloudflare.com/workers-ai/features/function-calling/traditional/).
The token stays in the Electron main process or Angular development proxy and
is not embedded in the frontend.

## Chat tools

Jarvas can search tasks and read task details, today's plan, time summaries,
projects, tags, notes, and recurring rules. It can reorder open tasks in
today's plan and create, edit, complete, reopen, schedule, unschedule, archive,
restore, and delete tasks; create
subtasks; change task tags, deadlines, reminders, and recurrence; move tasks to
or from a project backlog; start or stop tracking; and add time entries. It can
also create, edit, archive, and delete projects; create, edit, and delete tags;
create, edit, move, and delete notes; and open a project, tag, or Today view.

Task, project, tag, and note deletion always pauses for a one-time confirmation
code in chat. Type the exact displayed CONFIRM code in your next message to
continue, or type cancel. The code expires after five minutes. Project
deletion also removes its tasks and notes. These one-time confirmation codes
are removed from conversation history before any later request is sent to
Cloudflare.

## Data sent to Cloudflare

Each request sends the chat conversation and the tool data needed for that
turn. This can include task, project, and tag names and IDs; task status,
schedule, estimates, time entries, and recurrence details; plus tool arguments
and results. Task notes and note bodies are excluded unless you explicitly ask
Jarvas to inspect or work with their content. A note you ask Jarvas to create
or edit is included because it is the requested input. The API token is never
sent to the model.

When you use voice recording, the audio is sent to Cloudflare Workers AI for
transcription after you stop recording. Jarvas keeps the recording in memory
only while recording and transcribing; it does not save the audio.

Task changes run through Jarvas's existing app services and actions, so the
normal local persistence and configured sync behavior apply. Chat history is
saved in this app profile's local IndexedDB and remains available after closing
the Assistant page or reloading the app. Select a titled chat in the sidebar to
continue it; **New thread** starts a separate conversation. Each title is
generated locally from the first user message. Chat history stays on this device
and is not included in app backups or exports and does not sync to other
devices. Clearing the browser or app's local data removes it.

Assistant replies render common Markdown formatting, including headings, lists,
links, tables, and code blocks. The conversation stays in a centered reading
column, with the composer docked below the scrollable messages.

## Image attachments

Use the plus button in the composer to attach PNG, JPG, WebP, or GIF images.
Jarvas shows a preview before sending and lets you remove an attachment. It
accepts up to three images per message, up to 5 MB each, with a combined
12 MB limit. The image is sent to Cloudflare Workers AI with that message for
visual analysis; the configured Gemma 4 model supports vision and the chat API
accepts inline image URLs. See Cloudflare's [Gemma 4 model information](https://developers.cloudflare.com/ai/models/%40cf/google/gemma-4-26b-a4b-it/)
and [Workers AI chat completions example](https://developers.cloudflare.com/ai/models/meta/muse-spark-open/).

Image attachments are saved with the local chat thread in IndexedDB. When a
request includes a long conversation, Jarvas sends the four most recent images
alongside the text history to keep request size bounded. Older image previews
remain in the saved thread but are not sent to the model again.

Chat tools cover personal productivity work. They do not change sync or backup
configuration, import or export user data, manage credentials or plugins, or
run arbitrary commands.

Voice input records with the browser's media recorder after you press the
microphone button. Press the microphone again to stop and transcribe; recordings
stop automatically after two minutes. The audio is sent to Cloudflare Workers
AI's Whisper model only after recording stops, and the transcript is inserted
into the composer without sending the chat message. Audio recordings are not
saved by Jarvas. Microphone access is required; in the desktop app, only
microphone audio is allowed and camera access remains blocked.

The chat interface is included in the app's local build. It does not download
its code, styles, fonts, or other assets from a remote host.
