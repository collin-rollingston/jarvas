# Assistant Chat (Pilot)

The Assistant page is an early chat interface pilot. Open it from the app's
navigation. It provides a thread rail, a new-thread action, prompt suggestions,
and a chat composer. Use **Back to tasks** in the chat header to return to the
existing task interface.

The composer and prompt suggestions are disabled until an agent is connected by
the app. This pilot does not configure an agent service or send messages
anywhere. Chat messages are temporary. **New thread** clears the current
conversation, and messages are cleared when the Assistant page is closed or the
app reloads.

Voice input uses the browser's speech-recognition service when supported and
requires microphone access. Depending on the browser, audio may be processed by
a remote speech service. The browser requests access only after you press the
microphone button.

The chat interface is included in the app's local build. It does not download
its code, styles, fonts, or other assets from a remote host.
