# Assistant Chat (Pilot)

The Assistant page is an early chat interface pilot. Open it from the app's
navigation. Use **Back to tasks** to return to the existing task interface.

The composer is disabled until an agent is connected by the app. This pilot does
not configure an agent service or send messages anywhere. Chat messages are
temporary and are cleared when the Assistant page is closed or the app reloads.

The chat interface is included in the app's local build. It does not download
its code, styles, fonts, or other assets from a remote host.
